- Tool. `scripts/ops/ingest-corpus.ts`, with pure logic in library/corpus-manifest.ts, corpus-run.ts and corpus-report.ts.

  - It is a dry run by default and prints a cost and time estimate (£0.02–£0.05 per video; time from queue concurrency × workers × an ASSUMED 3 min per video, to be replaced by the sample's measured rate).
