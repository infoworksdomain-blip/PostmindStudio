model catalogue: `src/lib/studio/providers/fal-models.ts`; prices: `src/lib/studio/providers/pricing.ts`

Notes on prices:

- MiniMax H3 Max: the pages show a 40%-off promotion until 15 October ($0.048/s at 768p); Studio
  records the regular rate so cost caps stay conservative. "H3 Max" is the top MiniMax video
  family on fal (https://fal.ai/explore/minimax); its output has no audio track.
- LTX-2.3 Fast: the model page table says $0.04/s at 1080p, the `llms.txt` API page says
  $0.06/s. Studio records $0.06/s until a real invoice settles it.
- Veo 3.1 Lite exists on fal (both endpoints); Studio already has Veo 3.1 Fast directly through
  the Gemini API, so this is only an extra option.

Input schemas came from `https://fal.ai/api/openapi/queue/openapi.json?endpoint_id=<id>`.
Studio asks for silent clips (`generate_audio: false` on LTX and Veo; H3 Max has no audio).

## Queue API

https://fal.ai/docs/model-apis/model-endpoints/queue — `POST https://queue.fal.run/<endpoint>`
with `Authorization: Key <FAL_KEY>` → `request_id`; `GET …/requests/<id>/status` (IN_QUEUE,
IN_PROGRESS, COMPLETED with optional `error` / `error_type`); `GET` the status's `response_url`
(or `…/requests/<id>/response`) → `video.url`; `PUT …/requests/<id>/cancel`. Errors:
https://fal.ai/docs/documentation/model-apis/errors.md. Health check: the platform pricing
read `GET https://api.fal.ai/v1/models/pricing?endpoint_id=<id>`
(https://fal.ai/docs/documentation/model-apis/pricing.md).

Output files are public URLs on fal's CDN with the account's media expiration; the pipeline
copies each clip into the assets bucket as soon as the poll succeeds.

## Turning it on

```
FAL_KEY=<API key from the fal dashboard>
STUDIO_FAL_VIDEO_MODELS=ltx-2.3-fast,minimax-h3-max   # preference order
```

Empty `STUDIO_FAL_VIDEO_MODELS` (the default) = fal is not registered and routing is unchanged.
When set, the router uses `fal` in its existing BASIC slot (after Seedance, Kling, Veo) and as
the last resort on paid tiers (after Luma); the first listed model that fits the shot is used.

## One model from a script

`npm run gate2:fal -- <model>` (scripts/test-fal.ts) makes one paid 6 s clip with one model. In
code:

```ts
import { createFalModelAdapter } from '../src/lib/studio/providers/fal';
const adapter = createFalModelAdapter('minimax-h3-max', { usdToGbpRate: usdToGbpRateFromEnv() });
// then runTrackedJob(adapter, { capability: 'text_to_video', … }) as scripts/test-luma.ts does
```

## Not verified (no key)

- fal's live status / response URLs for these endpoints (the docs and OpenAPI agree on
  `/<endpoint>/requests/<id>/…`; the adapter prefers the status's `response_url`).
- The wording of fal's out-of-balance error (not documented); treated as insufficient credits
  when it says "exhausted balance" / "insufficient balance" or the shared out-of-credit wording.
- Whether fal bills the requested or the delivered seconds.
